commit and push

make sure it includes a prefix like
feat:
fix:
docs:
tui:
core:
ci:
chore:

For packages/web changes, use appropriate prefixes like:
- feat: for new features
- fix: for bug fixes
- docs: only for documentation changes

For packages/app changes, use appropriate prefixes like:
- feat: for new features
- fix: for bug fixes
- chore: for maintenance work

Do NOT use ignore: unless the change should be skipped by tooling (CI, changelog).

prefer to explain WHY something was done from an end user perspective instead of
WHAT was done.
